# 🍔 Food Ordering System

A desktop-based **Food Ordering System** developed using **C#**, **Windows Forms**, and **Oracle Database**. The application allows users to register, log in, browse the food menu, manage a shopping cart, place orders, make payments, and submit feedback.

---

## ✨ Features

- 👤 User Registration & Login
- 🍽️ Food Menu
- 🛒 Add Items to Cart
- ✏️ Update Item Quantity
- ❌ Remove Items from Cart
- 💰 Automatic Grand Total Calculation
- 💳 Online Payment
- 🚚 Cash on Delivery
- 📝 Feedback System
- 📦 Order Confirmation

---

## 🗄️ Database Setup

1. Install Oracle Database (XE or compatible version).
2. Create the required database tables.
3. Update the Oracle connection string in the project before running.

Example:

```csharp
User Id=YOUR_USERNAME;
Password=YOUR_PASSWORD;
Data Source=localhost:1521/XE;
```

> **Note:** The repository does not include my personal Oracle credentials.

---

## ▶️ How to Run

1. Clone this repository.

```bash
git clone https://github.com/trishaparmar2907-debug/Food-Ordering-System.git
```

2. Open **foodorderingsystem.sln** in Visual Studio.

3. Restore the required NuGet packages.

4. Configure the Oracle connection string.

5. Build and run the project.
